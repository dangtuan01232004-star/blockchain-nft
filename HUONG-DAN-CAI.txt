PHÁT HIỆN DÒ LỖ HỔNG (SQL injection / XSS / NoSQL / ../ / công cụ quét)
=====================================================================

1) Chép file backend/src/services/probeDetect.js vào đúng thư mục trong project.

2) Mở backend/src/server.js, thêm 2 chỗ:

   (a) Ở đầu file, cạnh các dòng require khác, thêm:
       const { probeDetectMiddleware } = require("./services/probeDetect");

   (b) Tìm dòng:
       app.use(express.json({ limit: "5mb" }));
       Thêm NGAY BÊN DƯỚI nó:
       app.use("/api", probeDetectMiddleware);

3) Push:
       git add backend/src/services/probeDetect.js backend/src/server.js
       git commit -m "Phat hien do lo hong SQLi/XSS"
       git push

Hoạt động:
 - Request có payload tấn công -> trả 400, ghi Nhật ký bảo mật kèm mẫu payload,
   admin nhận Telegram "IP ... đang DÒ LỖ HỔNG" (tối đa 1 tin / IP / 15 phút).
 - Nếu project đã có tính năng chặn IP (services/ipBlock.js) -> dò từ 3 lần trong
   10 phút thì tự chặn IP 1 giờ. Chưa có thì chỉ cảnh báo, không lỗi gì.
